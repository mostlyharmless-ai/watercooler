# Watercooler Trademark Policy

"Watercooler" and the Watercooler logo (collectively, the "Marks") are
trademarks of Mostly Harmless AI. This policy explains how you may use
the Marks while respecting our rights.

This policy aims to be **permissive for the community** while preventing
confusion about what is official and what is not.

## You MAY use the Marks without asking when you:

- Refer to the Watercooler project in articles, talks, tutorials, or
  documentation (e.g., "How to set up Watercooler for your team")
- State compatibility or interoperability (e.g., "works with Watercooler",
  "compatible with Watercooler protocol", "built on Watercooler")
- Use the name in source code comments, dependency lists, or package
  metadata that accurately describes a relationship to the project

## You MUST NOT use the Marks to:

- Name your own product, project, or service in a way that implies it IS
  Watercooler or is endorsed by Mostly Harmless AI (e.g., "Watercooler Pro",
  "Watercooler Hub", "WatercoolerDB")
- Offer a hosted or managed service under the Watercooler name
- Use the logo as your own, or modify it and present it as official
- Imply official endorsement, sponsorship, or affiliation where none exists
- Register domain names containing "watercooler" in a context that could
  cause confusion with the project (e.g., watercooler-cloud.io)

## Forks and derivative works

If you fork or substantially modify Watercooler, you must choose a
different name for your project. You may state the origin, e.g.,
"YourProject, originally based on Watercooler" — but the fork itself
must not be called "Watercooler" or use the Watercooler logo.

This requirement exists to prevent user confusion, not to discourage
forking. Apache-2.0 explicitly permits forking and modification.

## Community events and meetups

You may use the Watercooler name in community events (e.g.,
"Watercooler Meetup NYC") with prior written permission from
Mostly Harmless AI. Contact us at the address below.

## Integrations and plugins

Plugins and integrations may reference Watercooler to describe their
function, using formats like:

- "X for Watercooler"
- "Watercooler plugin for Y"
- "Compatible with Watercooler"

But not:

- "Watercooler X" (implies it is part of the official project)
